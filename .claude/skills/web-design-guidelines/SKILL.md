# Web Interface Guidelines

Review files for compliance with Vercel's Web Interface Guidelines.

## How it works

1. Read the rules in `guidelines.md` next to this file (a pinned copy of
   vercel-labs/web-interface-guidelines `command.md`, MIT).
2. Read the specified files (or ask which files to review).
3. Check them against every rule.
4. Report findings in the terse `file:line` format the guidelines describe.

## Project note

This repo's copy rules win where they conflict: keep straight quotes and
apostrophes (the guidelines prefer curly quotes) and avoid em dashes.
